# Sai Portfolio

Static portfolio ready for Vercel. Edit `index.html` to replace `hello@example.com`, LinkedIn, project names, and descriptions with your exact details.

## Deploy

1. Create a new GitHub repository and upload this folder.
2. In Vercel, select **Add New → Project**, import the repository, and click **Deploy**. No framework or build command is required.
3. Add a custom domain in the Vercel project’s **Settings → Domains** when ready.

For local preview, open `index.html` in a browser. The site uses no dependencies or build process.
